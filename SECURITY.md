# Security reporting

Report suspected vulnerabilities against the current main branch. If GitHub’s private vulnerability reporting is available in the repository’s Security tab, use it. Otherwise open an issue requesting a private reporting channel without publishing exploit details, credentials or personal data.

Include the affected version/commit, impact, minimal reproduction and relevant environment details. Do not test against other players, exhaust public room capacity or access another person’s data. No response-time or bounty commitment is implied.

The server owns online movement, collisions and race results. Coins, cosmetics, solo records and saves are stored in the player’s browser and can be edited by that browser’s owner. They are not an authority for paid currency or a global competitive leaderboard. Online rooms are held in server memory and do not survive restarts.

The application needs no player login or application API keys. Deployment supplies PORT; Render can supply RENDER_GIT_COMMIT for release identification. Do not publish environment values or tokens in issues, screenshots or commits.
